# SR Investment Platform

A modern investment platform landing page and user flow built with React, Vite, and Tailwind CSS. The project includes sections for home, investment plans, registration, login, KYC/security, support, terms, privacy, checkout, and withdrawal guidance.

## Live Demo

https://developer-faisal06.github.io/SR-Investment-Platform/

## Features

- Modern responsive investment platform UI
- Investment calculator with growth visualization
- Login and registration pages
- Investment plans and checkout flow
- KYC and security section
- Support, contact, terms, and privacy pages
- Clean React-based component structure

## Tech Stack

- React
- Vite
- React Router
- Tailwind CSS
- Lucide React

## Run Locally

```bash
npm install
npm run dev
```

Then open the local Vite URL in your browser.

## Production Build

```bash
npm run build
```
